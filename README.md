Projeto: Um resumo sobre o futebol

Este projeto é um site desenvolvido puramente em HTML5, sem a utilização de CSS ou bibliotecas externas. 

 Estrutura do Projeto
- `index.html`: Página principal contendo introdução ao futebol, estatísticas de partida (usando `meter`), citações e vídeos.
- `html/historia.html`**: Página detalhando a história das Copas do Mundo, utilizando tabelas complexas, tags de deleção/inserção de texto e áudio local.
- `html/contato.html`**: Formulário avançado de recrutamento para novos talentos utilizando inputs semânticos modernos.

 Requisitos Cumpridos
- Organização em pastas na raiz (`html/`, `img/`, `audio/`, `video/`).
- 3 páginas interligadas com navegação relativa fluida.
- Tags semânticas de layout rigorosamente aplicadas (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- Tabelas com atributos de mesclagem estrutural (`rowspan`).
- Formulários com validação nativa, `datalist` e inputs avançados (`date`, `range`, `file`).
- Tags de mídia nativas apontando para arquivos locais.
- Sem uso de CSS (`style`, `<style>`, tags visuais depreciadas).
